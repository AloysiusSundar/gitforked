Yathir.ai is a high-performance travel itinerary solver built to enforce strict time-window routing and anchor hard reservations for multi-day trips.

## Key Technical Innovations
- **FastAPI Dynamic Programming Solver:** Enforces strict time-window constraints across multi-day itineraries.
- **Geospatial Radial Clustering:** Partitioned 50+ points of interest into daily sectors to minimize travel overhead.
- **LLM Natural Language Parser:** Extracted complex constraints from conversational user prompts with vector similarity ranking.
